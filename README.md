# Sales Analysis

## Project Overview

This project analyzes Diwali sales data using Python to understand customer purchasing patterns and sales trends.

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed

- Data cleaning and preprocessing
- Gender-wise analysis
- Age-group analysis
- State-wise customer analysis
- Zone-wise analysis
- Occupation analysis
- Product category analysis
- Purchase amount analysis
- Data visualization

## Key Insights

- Analyzed customer purchasing patterns across different genders.
- Compared customer distribution across states and zones.
- Identified popular product categories.
- Analyzed the distribution of purchase amounts.
- Examined the relationship between customer age and purchase amount.

## Project File

- `Analysis.ipynb` – Complete Python analysis with visualizations.

## Conclusion

The project demonstrates how Python and data visualization techniques can be used to analyze customer behavior and identify useful sales patterns.
